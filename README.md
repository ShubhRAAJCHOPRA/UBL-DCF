# UBL-DCF Overview

This project presents a comprehensive equity research and valuation analysis of United Breweries Ltd. (UBL), combining historical financial analysis with a forward-looking Discounted Cash Flow (DCF) valuation.
The objective is to understand UBL's financial performance, operating drivers, future growth potential, and intrinsic value using a structured financial modelling approach.
Project Highlights
- 📊 5-year historical financial analysis
- 📈 Revenue, EBITDA and EBIT analysis
- 💰 Profitability and return ratio analysis
- 🔄 Working capital analysis
- 🏭 Capital expenditure and depreciation analysis
- 📑 Financial statement forecasting
- 🧮 WACC calculation
- 💵 FCFF-based DCF valuation
- 📉 Terminal value and sensitivity analysis
- 🏢 Comparable Company Analysis
- 📊 Trading peer multiples
- 👥 Shareholding pattern analysis
- ⚠️ Key risks and valuation considerations
DCF Model Structure
The Excel model is structured across four primary sections:
1. Assumptions
Key operating and valuation assumptions used throughout the model, including:
- Revenue growth
- Operating margins
- Tax assumptions
- Working capital
- CAPEX
- Depreciation
- WACC
- Terminal growth
2. Working
Detailed schedules supporting the valuation:
- Revenue forecast
- Income statement projections
- Working capital
- CAPEX
- Depreciation
- Debt
- Cash flow
- FCFF
- DCF valuation
3. Financial Statements
Historical financial statements and key financial metrics used as the foundation for forecasting.
4. Valuation
DCF valuation, terminal value, enterprise value, equity value and sensitivity analysis.
Valuation Approach
The primary valuation methodology used is Discounted Cash Flow (DCF) based on Free Cash Flow to Firm (FCFF).
The general framework is:
Revenue → EBITDA → EBIT → NOPAT → FCFF → Enterprise Value → Equity Value → Intrinsic Value per Share
The model also incorporates a Comparable Company Analysis (CCA) to provide a market-based valuation perspective.
